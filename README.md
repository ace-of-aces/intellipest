## Features

- 🧠 Smart helper file generation for PestPHP
- 🫵🏻 Supports your custom test cases
- 🧩 Pure PHP & framework agnostic

> [!IMPORTANT]
> This project is currently in beta. Features are subject to change.

## Introduction

IntelliPest is a CLI tool that generates a helper file based on your own Pest setup.

This assists your IDE or coding agent to better understand your tests, enabling full autocompletion and error checking for [compatible language servers](https://intellipest.julian.center/compatibility).

Editors/IDEs and Coding Agents which can benefit from this include [VS Code](https://code.visualstudio.com), [Cursor](https://cursor.com), [Zed](https://zed.dev) and [OpenCode](https://opencode.ai).
